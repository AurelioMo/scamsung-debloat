Home / Privacy

No account. No tracking.

This is a static documentation site. It does not set cookies, does not run analytics, and has nothing to sign in to. What follows is the complete list of what leaves your browser.

When you read these pages

The site is served by GitHub Pages. GitHub receives the usual request data for every page: IP address, user agent, the file requested and the time. That is how any web server works, it is outside this project's control, and it is covered by GitHub's privacy statement.

Web fonts

Pages request the Manrope typeface from fonts.googleapis.com and fonts.gstatic.com. Those requests expose your IP address and user agent to Google, which is covered by Google's privacy policy. No font is used to identify you.

When you run the script

The script is bash running on your computer. It talks to adb over the USB cable and to nothing else: no telemetry, no update check, no remote list. Its only persistent output is local, under ~/.local/share/scamsung-debloat/ — the state file and one log per session. Delete that directory and the script forgets every removal it made.

Links out

Links to GitHub, Google, Samsung and other sites leave this one. Each destination has its own privacy policy, and none of them are covered here.

Changes

If the site ever adds something that collects data, this page changes in the same commit. Today it collects nothing.

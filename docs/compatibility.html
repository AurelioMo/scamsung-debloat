Compatibility

Built for Galaxy phones on One UI 8/9. Works on any computer with bash and adb. Honest limits below.

Phones and One UI versions

FirmwareStatus
One UI 8/9 (Android 16/17) Target. Presets are based on lists community-tested on One UI 8/8.5/9 (itxjobe/samsungdebloat).
One UI 7 and older Same mechanism; some preset packages simply won't exist and are skipped.
Newer / unseen versions The tool prints a version warning, then proceeds — it only touches packages that exist on the phone, and the deny-list always applies.

Any Galaxy model runs the same pm --user 0 commands — S, Z, A, M, Note, Tab. The presets describe phone apps; on tablets and foldables some lines may not apply (they will show as "missing on device" and be skipped). Deep, version-by-version notes live in the repository: docs/oneui-compat.md (pt-BR).

Computers

HostRequirement
macOSWorks with the stock bash 3.2 — nothing else needed beyond adb.
LinuxAny distro with bash + platform-tools.
WindowsGit for Windows (Git Bash) + platform-tools; double-click the .cmd wrapper.

Interface language follows the OS: Português, English, Español (SCAMSUNG_LANG overrides).

Known limitations

  • No storage freed. APKs remain in the read-only system partition; you gain RAM, battery and privacy, not gigabytes.
  • OTAs can reinstall apps. Re-run the preset after major Samsung updates.
  • Package renames degrade gracefully. If Samsung renames a package, the preset line just stops matching. Removals are never guessed.
  • Carrier firmware (US models). Carrier-specific apps are intentionally not in the presets — they vary too much. Use apply --only <package> after checking with explain <package>.
  • Galaxy AI is your choice. AI features are deliberately kept out of the presets — remove them individually only if you don't use them.
  • Tested on a simulator. The automated suite uses a fake adb; no physical model matrix exists. Report firmware-specific oddities in issues.

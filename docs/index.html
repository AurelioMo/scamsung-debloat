Samsung debloat, minus the scary parts

Remove Galaxy bloatware on One UI 8/9 without root. Double-click a file, pick numbers from a menu, review the exact list of what leaves your phone, and undo everything with one command.

Install in 5 minutes View on GitHub

No root. Ever.

Everything runs through adb shell pm … --user 0 — the stock Android mechanism. Knox, bootloader and warranty are never touched.

Preview before anything

You always see the full removal list first and must type sim to continue. There is no way to skip the preview.

Reversible by design

Every action is logged. Restore everything brings each app back; tweaks restore their exact original values.

Honest presets

Each of the 51–126 packages in a preset has a plain-language line saying what it is and what stops working without it.

Your language

The whole interface — menus, warnings, errors — speaks Português, English or Español, following your OS automatically.

Tested, not on your phone

73 automated checks run against a fake adb simulating a Galaxy on One UI 9. No real device is ever needed to validate the tool.

How it works

scamsung-debloat is a single bash script (with tiny Windows wrappers). When you pick a preset, it asks your phone which packages actually exist, subtracts a built-in deny-list of critical components, shows you what remains, and only then removes apps from your user profile:

  1. Diagnostics — checks adb, the device and your Android/One UI version.
  2. Preview — prints every package to be removed, each with its explanation, plus counts of what is already gone or missing.
  3. Confirmation — type sim. Anything else cancels safely.
  4. Apply — pm uninstall --user 0 per package; failures fall back to disabling the app (data preserved).
  5. Undo anytime — menu option 4 restores everything this tool ever removed.

light98 Everything in basic, plus Chrome, Gmail, "Ok Google", Android Auto, Galaxy Themes, Samsung Pass, Wallet, Bixby, Find My Mobile. Medium. Only if you already replaced those with other apps.

Never removed, in any preset: Play Store/Services, SystemUI, Settings, the One UI launcher, phone/dialer, IMS/VoLTE/Wi-Fi calling, Samsung keyboard and the setup wizard — see the deny-list.

Why not Canta or UAD?

Universal Android Debloater and Canta are great projects — scamsung-debloat borrows risk knowledge from them. It exists for the people they don't serve well: Galaxy owners who don't want to learn a new app, who want a menu in their own language, presets built specifically for One UI 8/9 (based on itxjobe's community-tested lists), and a restore path that doesn't depend on keeping Shizuku alive.

Quick answers

Does it need root? Does it trip Knox?

No and no. It uses adb shell pm … --user 0, a stock Android feature. Bootloader, /system, Knox and Play Integrity are untouched.

Can I undo it?

Yes — menu option 4 restores everything the tool removed, and tweaks --reset restores every setting to its recorded original value.

Will an OTA update bring the apps back?

Samsung OTAs sometimes reinstall their apps. Nothing breaks — run the same preset again.

Does it free up storage?

No: APKs stay in the read-only system partition. The gains are RAM, background battery drain, privacy and a clean app drawer.

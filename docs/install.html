Five minutes, then seconds.

You only type things in step 1 — the tool itself is a double-click menu that follows your language.

Install adb — once per computer

PlatformCommand
macOSbrew install --cask android-platform-tools
Windowswinget install --id Google.PlatformTools -e
plus Git for Windows — the tool uses its bash
Debian/Ubuntusudo apt install android-tools-adb
Fedorasudo dnf install android-tools
Archsudo pacman -S android-tools

Manual alternative on any platform: the official platform-tools ZIP from Google, folder added to your PATH.

Prepare the phone — once per phone

  1. Settings → About phone → Software information
  2. Tap Build number 7 times — Developer options unlocked.
  3. Settings → Developer options → USB debugging → ON.
  4. Plug the cable in and tap Allow on the phone's prompt.

No cable? Menu option 7 pairs over Wi-Fi instead (Android 11+ wireless debugging).

Run it — no typing

  1. Get the repo: download the ZIP and extract, or git clone https://github.com/AurelioMo/scamsung-debloat.git
  2. Double-click: Windows scamsung-debloat.cmd · macOS scamsung-debloat (first time: right-click → Open → Open) · Linux scamsung-debloat → Run in Terminal (or enable "Allow executing file as program").
  3. Recommended first run: 1 diagnostics → 2 apply → basic → read the preview → type sim.

Nothing is removed before you type sim. Closing the window, Ctrl+C or any other input cancels without touching the phone.

Prefer the command line?

Every menu action has a flag equivalent — same preview, same confirmation:

./scamsung-debloat doctor            # diagnostics
./scamsung-debloat list              # show presets
./scamsung-debloat apply basic       # preview → type "sim" → apply
./scamsung-debloat apply --only com.facebook.katana
./scamsung-debloat explain <package> # what is this package?
./scamsung-debloat restore           # undo everything
./scamsung-debloat tweaks --status   # what tweaks changed

Options: -y skip typing (preview still shown) · --disable disable instead of uninstall (keeps data) · --skip a,b · --serial · -v/-q · --help · --version

Interface language

The tool follows your OS automatically — Português, English or Español. Override with SCAMSUNG_LANG=pt|en|es.

Install & first run

About five minutes the first time; under one minute after that. You only type things in step 1 — the tool itself is a double-click menu.

1. Install adb (once per computer)

PlatformCommand
macOSbrew install --cask android-platform-tools
Windowswinget install --id Google.PlatformTools -e
(also install Git for Windows — the tool uses its bash)
Debian/Ubuntusudo apt install android-tools-adb
Fedorasudo dnf install android-tools
Archsudo pacman -S android-tools

Manual alternative for any platform: download the official platform-tools ZIP from Google and put its folder on your PATH.

2. Prepare the phone (once per phone)

  1. Settings → About phone → Software information
  2. Tap Build number 7 times — Developer options is now unlocked.
  3. Settings → Developer options → USB debugging → turn it ON.
  4. Plug the USB cable into the computer and tap Allow on the phone's "Allow USB debugging?" prompt.

No cable? The tool's menu option 7 pairs over Wi-Fi instead (Android 11+ wireless debugging).

3. Run it (no typing)

  1. Download the repository: ZIP (extract it) or git clone https://github.com/AurelioMo/scamsung-debloat.git
  2. Double-click:
    • Windows: scamsung-debloat.cmd
    • macOS: scamsung-debloat — first time only: right-click → Open → Open (Gatekeeper bypass for unsigned scripts).
    • Linux: scamsung-debloat → choose Run in Terminal. If nothing happens, enable "Allow executing file as program" in the file's properties (or chmod +x scamsung-debloat).
  3. A numbered menu appears. Recommended first run: 1 (diagnostics) → 2 → basic → read the preview → type sim.

Nothing is removed before you type sim. Closing the window, pressing Ctrl+C or typing anything else cancels without touching the phone.

Prefer the command line?

Every menu action has a flag equivalent — same preview, same confirmation:

./scamsung-debloat doctor            # diagnostics
./scamsung-debloat list              # show presets
./scamsung-debloat apply basic       # preview → type "sim" → apply
./scamsung-debloat apply --only com.facebook.katana
./scamsung-debloat explain <package> # what is this package?
./scamsung-debloat restore           # undo everything
./scamsung-debloat tweaks --status   # what tweaks changed

Options: -y (skip typing, preview still shown), --disable (disable instead of uninstall, keeps app data), --skip a,b, --serial, -v/-q, --help, --version.

Interface language

The tool follows your OS language automatically — Português, English or Español. Override with SCAMSUNG_LANG=pt|en|es.
